SQL Injection Testing Lab (C)

This lab demonstrates SQL Injection vulnerabilities using a deliberately
unsafe C application backed by SQLite.

## Components
- Vulnerable login app (string concatenation)
- Shell-based SQL injection test
- Secure version using prepared statements

## Learning Objectives
- Understand why SQL injection happens
- Learn how attackers bypass authentication
- See how prepared statements eliminate the issue

⚠️ For educational use only. Run locally.
